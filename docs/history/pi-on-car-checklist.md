# 上车标定与验证清单

## 1. 相机

- 固定相机高度、俯仰角、横滚角和分辨率，运行期间不要移动。
- 当前水平舵机正前方角度为 `25°`，实时入口会在打开相机前自动回正。
- 机械位置变化后，先用 `tools/capture_onboard.py` 采集，再用
  `tools/calibrate_perspective.py` 重做鸟瞰标定。
- 使用离线回放确认左右边界、中心线和单边界续接方向正确，再启用电机。

## 2. 底盘

- 用 `tools/check_wheel_directions.py` 架空检查四轮，当前映射为
  `0=左前、1=左后、2=右前、3=右后`。
- 检查每个轮子的启动死区；某一轮偶发不动时先排查接线、电机死区和供电压降。
- 确认正转向量让车辆向右，负转向量让车辆向左。

## 3. 上车顺序

1. 先离线回放最近一次 `raw.mp4`，确认故障帧不再触发错误停车或错误转向。
2. 架空车轮运行电机测试，确认急停能立即让四轮归零。
3. 在空旷直道低速验证居中，再进行单弯和整圈测试。
4. 每次只修改一组参数，并保留 `outputs/onboard_runtime/runs/` 下的完整实验归档。

## 4. 必须停车的情况

- 相机断流、处理看门狗超时或运行达到最大时长。
- 黄色边界进入车体足迹，或有效道路边界真正丢失。
- 单边界恢复持续没有进展，或横向/航向误差超过安全阈值。
- 操作者点击网页停止/急停、关闭网页服务或按下 `Ctrl+C`。

实车运行时必须有人在车辆旁准备急停或切断电机电源。
