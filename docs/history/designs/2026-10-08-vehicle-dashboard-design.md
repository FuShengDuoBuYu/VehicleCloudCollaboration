## 用户目的与验收结果

用户在实验现场通过电脑或手机浏览器查看小车基本状态与自动驾驶状态。车辆开机后 HTTP 服务自动可用，包含电池、相机、雷达、深度、IMU/编码器、YOLOPv2、控制置信度、云端触发/结果和任务目标。保留现有 LCC 面板可用能力，清楚标注实时、过期、未配置、未接入、异常和历史数据。

默认解释：开机自动提供面板与可用的状态采集，不自动授权车轮运动；浏览器由访问者打开。当前访问范围为同一局域网，拟用 http://10.20.30.132:8080/，地址可能随 DHCP 改变。若需要车载显示器登录后自动打开页面，可独立增加桌面启动项；这与系统开机启动 HTTP 服务不同。

## 方案选择

1. **扩展现有 LCC 面板（推荐）**：复用过程管理、JPEG 和诊断数据，新增状态聚合与传感器发布协议。无前端构建依赖，现场部署成本小。
2. 独立新面板：便于重新设计，但会重复过程管理与状态读取，需要兼容两套入口。
3. 全面改为 ROS 导航监控：适合后续 SLAM/定位，但当前车端控制不是统一 ROS 架构，扩大本次范围且需要迁移。

选择方案 1。下述实现不要求重新安装已验证的 GPU 环境，不要求新增 SLAM、规划器或真实云模型。

## 页面与数据

| 区域 | 展示内容 | 数据来源与限制 |
|---|---|---|
| 总览 | 服务连通、运行模式、运行 ID、最近更新时间、电机是否启用、当前停止原因 | 程序生命周期与运行状态；虚拟 PWM 明确标注 |
| 电源/主机 | 电池电压、温度、内存/磁盘、进程状态 | 底盘遥测与只读系统接口；未有电池型号/曲线时百分比为空 |
| 摄像头 | 实时图、采集帧率、分辨率、帧龄、异常 | 复用单一采集者，不为每个浏览器打开摄像头 |
| 传感器 | 雷达频率/有效点/最近有效距离及简图；深度有效比例/距离；IMU/姿态、编码器 | 实际驱动发布；设备存在、驱动工作、有效数据分开 |
| 感知 | 道路/车道/目标框叠加、类别与检测置信度、模型设备/精度、推理耗时、结果年龄 | YOLOPv2 已有状态，缺失字段明确待发布；不以检测置信度代表驾驶安全概率 |
| 自动驾驶 | 运行/等待/停车/恢复、轨迹与前视点、LCC 置信度、提案和实际命令状态、门禁/看门狗 | 控制器只读快照；不改变控制决策 |
| 云端 | 启用/未接入、触发原因、event/request ID、请求中/超时/失败/完成、耗时、场景/风险/建议、不确定性、本地采纳或拒绝原因 | 运行时发布事件；未接入不能写“未触发”，历史结果不作当前结果 |
| 任务 | 当前任务、路线约束、最终目的地、局部前视点 | 分别显示；没有定位/全局导航时最终目的地标为“未配置/未接入” |

正常状态与断线提示使用文字加颜色。云端文本用文本节点渲染，避免作为 HTML 执行。页面掉线立即显示断线并停止“在线”动画；旧图保留时显著注明时间和非实时。

## 运行结构

浏览器 → HTTP 状态聚合 → 运行时快照/传感器快照。聚合与 JPEG 编码均不在电机控制热循环中执行。

- `/`：综合面板，保留已有深度诊断区。
- `GET /api/state`：保留现有字段，向后兼容添加 `schema_version`、`system`、`sensors`、`cloud`、`navigation` 与每个来源的新鲜度。浏览器单个未完成请求期间不叠加轮询。
- `GET /api/health`：服务存活与数据源就绪状态；服务存活不等同于硬件正常。
- 保留当前图像端点；图像请求成功也须配合采集时间判断实时性。
- 状态优先每 0.5 秒刷新；图像约 2 Hz，避免挤占 Orin 推理资源。后台采集固定频率，多客户端不增加设备读取频率。
- 传感器快照由唯一设备拥有者原子写入固定目录。电压、IMU 和编码器共享底盘会话；面板不重复打开控制串口。运行时未接入共享发布时明确显示“未接入”，不以旧验收日志冒充实时值。
- 雷达/深度桥只启动必要传感器节点，发布有界摘要/抽样点，不自动运行导航或运动节点。连续采集与其它聊天的设备占用冲突时报告占用，不抢占或终止对方进程。
- 每个来源包含 boot/session/run 标识、采样时间、发布心跳和错误状态。过期阈值依据来源配置，生产者崩溃、JSON 损坏、文件缺失、重启后的残留文件均不能显示健康。
- 未实施的云端/导航接口保持显式能力状态；不为面板自行触发付费请求，也不把人工填写的目的地当成已实现导航。

## 启动、访问与控制边界

新增独立 Jetson 面板启动入口，明确选择已验证的 Python 环境及车辆 profile，避免 `run.sh` 的默认树莓派 profile。部署 `systemd` 服务，开机自动启动、异常有界重启、输出进 journal；监听局域网 HTTP 8080。配置与安装脚本可审查，安装前检查端口/同名服务，不覆盖已有服务。

面板默认不允许通过网络解除电机门禁。保留已有手动运行能力时，必须延续标定和现场确认；外部访问默认只读，不能把旧的无认证 POST 启动接口直接开放为车辆控制接口。跨站请求不接受为控制指令。网页停止按钮不是物理急停的替代品。

本次不配置公网端口转发；若用户另需跨网络访问，优先使用已有 SSH/VPN 访问并单独明确控制权限。密钥只由车端本地认证配置读取，不进入 API 返回、HTML、日志或 Git。
